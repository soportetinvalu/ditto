# Matriz de las 20 funciones del informe REA

**No es un certificado de paridad.** Se conserva la identidad F01–F20 del informe anterior; no se volvió a investigar el binario. Esta implementación original no se comparó con una sesión Windows/Store ni se compiló en macOS durante esta entrega.

Estados permitidos: **Implementada** = ruta de código concreta existente; **Pendiente** = parte construida pero falta una faceta relevante de la fila; **No aplicable** = fuera del alcance confirmado Mac/local. Toda fila que toca AppKit tiene además aceptación macOS pendiente, incluso cuando dice implementada. Pruebas C reales en `.verification/`; XCTest preparado no equivale a XCTest ejecutado.

## Barreras antes de llamar esto una aplicación entregada

1. **Compilar y ejecutar** `scripts/macos_executor.py` en Mac arm64 con herramientas ya disponibles. Linux no valida Swift/AppKit.
2. Completar `docs/ACEPTACION-MACOS.md` con fixtures sintéticos; no usar el portapapeles personal de la persona usuaria para pruebas.
3. Auditar código, licencias, retención, entradas SQLite/JSON y consumo de memoria. No se emitió auditoría independiente.
4. Decidir/finalizar las filas pendientes frente al objetivo «igualita funcionalmente». Esta entrega es una implementación amplia real para la siguiente fase, **no paridad completa ni release aprobada**.
